# Nova-Jinja2

Basic Jinja2 syntax highlighting extension for Nova IDE. Just the minimally usable basics initially--pull requests encouraged.

YAML files with `.yml` or `.yaml` extensions, including templates with `.yml.j2` or `.yaml.j2` extensions, use YAML highlighting with Jinja2 directives.
